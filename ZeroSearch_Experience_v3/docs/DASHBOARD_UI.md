# ZeroSearch Dashboard UI v2.3

This refresh is primarily a visual redesign of `backend/static/style.css`. It preserves the existing Flask routes, API calls, navigation `data-view` attributes, and dashboard IDs used by `backend/static/app.js`.

Highlights:
- Soft lavender/blue ambient background and glass-like sidebar.
- Improved typography, spacing, responsive behavior, and keyboard focus states.
- Refined hero panel, gradient typography, metric cards, badges, panels, forms, score ring, and empty states.
- Hover states are subtle and reduced-motion preferences are respected.
- Existing data behavior remains unchanged.
